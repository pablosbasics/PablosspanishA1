# Español A1 – Mein Lernplan

## Tägliche Routine (ca. 20 Minuten)

1. Start-Seite öffnen, "Heutige Lektion" starten.
2. Regel-Tabelle laut lesen, Beispiele mit 🔊 anhören und nachsprechen.
3. Übungen machen. Falsche Antworten nochmal in der Lektion üben.
4. Einmal pro Woche die Prüfungs-Simulation machen.

## Hinweis zur A1-Prüfung

Diese Seite deckt die Grammatik ab. Die A1-Prüfung (z. B. Goethe, telc oder DELE) hat außerdem Hör-, Lese- und Schreibteile sowie einen Sprechteil. Dafür lohnt es sich, zusätzlich täglich Hörübungen zu machen und Sätze laut zu sprechen.
